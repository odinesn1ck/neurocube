# Изолированный RAM-аудиотест

Диагностическая программа для Waveshare RP2350-Touch-LCD-1.54, не часть игровых модулей или production прошивки. Сигнал 1 кГц / 300 мс, затем отключение усилителя и перезапуск установленной прошивки. Flash API не используется. Не запускать автоматически; требуется прямое разрешение пользователя на тест и USB/BOOTSEL, идентификация serial/topology и сохранение records/settings до и после. USB должен оставаться подключён для восстановления.

Нужны Pico SDK 2.3.1, ARM GCC, CMake/Ninja; переменная WAVESHARE_AUDIO_ROOT указывает на examples/C/02_ES8311 из официального репозитория Waveshare, commit 51a7fe28c1e5dd19a089a062980a275709e94df6. Кодек и PIO используются из этого каталога без копирования; их лицензия остаётся в исходниках Waveshare. PICO_SDK_PATH — путь SDK. CMake задаёт pico_set_binary_type(no_flash). Перед запуском проверить все LOAD-сегменты ELF: только SRAM, никаких 0x10000000-адресов. Запуск через picotool load -v -x audio_probe.elf допускается только для идентифицированного устройства в BOOTSEL. Production Bridge flash для этого ELF не использовать.

Уровень 60/100 и PCM peak 8191 — проверенный тестовый режим, не подтверждённый максимум допустимой мощности. [Результат и ограничение интерпретации схемы](../../docs/evidence/audio-capability-2026-10-21.md).
