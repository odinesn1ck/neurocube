# Исторический RAM-аудиотест — выведен из использования

Исходники и CMake прежнего теста удалены: они подключали спорный ES8311 из внешнего Waveshare checkout и воспроизводили отвергнутый пользователем громкий PCM 8191. Пересобирать или запускать этот тест не следует. [Первичный результат исследования](../../docs/evidence/audio-capability-2026-10-21.md) сохранён как история.

Для разрешённой приёмки текущего драйвера используется production-кандидат с принятым PCM 1280 и codec volume 60; прошивка требует отдельного разрешения, backup журнала и identity/readback checks. Проверять штатные «кх»/«уоп», без диагностического громкого писка. [Задание замены](../../docs/tasks/replace-es8311-driver-license.md).
