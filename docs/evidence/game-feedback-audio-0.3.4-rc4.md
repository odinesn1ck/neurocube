# Звуковая обратная связь игр — 0.3.4-rc4, 22.10.2026

В rc3 касание стены без проигрыша намеренно не озвучивалось по исходному заданию; пользователь уточнил, что нужен звук каждого засчитанного контакта. Добавлен WallContact отдельно от ErrorOccurred. Новый контакт даёт один «кх», непрерывный упор не повторяет его, проигрышное касание даёт один ErrorOccurred. Режим без лимита сохраняет счётчик и звуковую обратную связь.

По новому указанию добавлен Success: «уоп» за цель лабиринта, полный повтор последовательности Simon и каждую верную команду Commands. Частичный повтор Simon не создаёт успеха раунда; визуальная фаза подтверждения не создаёт повторных звуков. Magic Ball сохраняет AnswerAccepted. App маршрутизирует события через прежний порт AudioOutput и общий игровой mute. Один голос, без наложений и очереди; новое событие при занятом голосе отбрасывается по прежней политике.

Пользователь принял громкость и управление rc3. PCM peak 1280, кнопка/область, синтез, аппаратный драйвер, заставки, процедура PWR, счётчики, сложность, рекорды и формат журнала не менялись.

Новые тесты: один контакт при удержании, один сигнал на проигрышное касание, количество событий равно количеству контактов; App маршрутизирует контакт в Error с mute ON/OFF, включая unlimited; Success Simon только за полный раунд; правильная команда через App даёт Answer с учётом mute; 300 прохождений программной физикой завершаются Success, последующие update не повторяют событие. Это проверки программной модели, не физическая приёмка платы.

Native: 10757 audio checks и полный core suite пройдены; 14 Python tests и галерея симулятора пройдены. UF2/CI готовятся. На устройстве остаётся rc3 / c90b616; rc4 требует отдельного разрешения перед прошивкой и физической проверки новых сигналов.
