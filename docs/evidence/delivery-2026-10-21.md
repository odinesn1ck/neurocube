# Итог работ NeuroCube — 21.10.2026

[PR #1](https://github.com/odinesn1ck/neurocube/pull/1) остаётся draft и не слит. [Релиз 0.3.0-rc1](https://github.com/odinesn1ck/neurocube/releases/tag/v0.3.0-rc1). Исходный коммит устанавливаемой прошивки: `bfa1a7313ddad293e17b1f882b92019e8fb7990e`.

## Выполненные этапы

1. Исследована схема питания, добавлен ранний BAT_EN HIGH. Пользователь подтвердил работу от аккумулятора 5+ минут. Зарядка и аппаратная схема не менялись.
2. Исправлены калибровка, Simon/Commands, лабиринт, Magic Ball и персонализация; сохранена Clean Architecture и реальные очки.
3. Документация стала базой знаний: стратегические источники, политика, обязательные правила AGENTS, актуальные backlog/progress/changelog, архивы и лёгкий валидатор ссылок. Документальный этап не менял прошивку.
4. Добавлены перспективные IT-титры, безопасный polling idle GPIO13 и поглощение wake; реализован QR-переход заставки. Нативные кадры и тесты сохранены.
5. Исправлен обнаруженный ARM-резерв стека. Реальная миграция журнала v3 прошла без потери очков/настроек; после перезапуска установлен production с отключённым debug.

## Проверки и границы

1529 C++ проверок, 13 Python проверок, QR decode с framebuffer, все девять карт, layout всех пар Magic Ball, естественный idle/PWM на финальной плате bfa1a73, реальная Flash-миграция и production USB smoke. Две независимые сборки совпали; скачанный из GitHub UF2 побайтно совпал с локальным. UF2 SHA256: `d59b63b199a135d73c83892117439238baa097632efd34aa5e1294fd01c4ec09`.

Полная классификация VERIFIED_ON_HARDWARE / VERIFIED_IN_SIMULATOR / COMPILED_ONLY / NOT_TESTED — в [progress](../progress.md). Физическое пробуждение, окончательная визуальная приёмка игр/QR, отдельный старт PWR и измерение потребления не заявляются проверенными. PWR-выключение удержанием не реализовано. CI не запущен: PAT не позволяет менять workflow (HTTP 403).
