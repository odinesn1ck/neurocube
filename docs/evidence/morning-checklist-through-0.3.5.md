# Ручная приёмка NeuroCube

## Звук 0.3.4 — после установки итогового профиля

1. При включении «Привет, Андрей» → один мягкий «уоп».
2. Выключить игровые эффекты пиктограммой на «Как играть»; запрос шара беззвучен. Перезапустить устройство: игровой OFF сохранён, приветствие всё равно звучит.
3. Удержать PWR до «Выключаюсь»: один короткий «кх», затем отпустить; проверить штатное выключение от аккумулятора.
4. Включить игровые эффекты: новый ответ шара → «уоп», ошибка игры → «кх», без повторов и наложений. Проверить прежние рекорды и калибровку.

## Повторная приёмка 0.3.3 — после разрешённой прошивки

1. С USB коротко нажать PWR: не выключается. PLUS остаётся игровым. Удержать PWR 1,8 с, увидеть «Выключаюсь», отпустить; с USB возможен «Питание осталось», касание возвращает меню.
2. Отключить USB. Длинное PWR → «Выключаюсь» → отпустить → устройство выключено. Новое PWR → «Привет, Андрей»; касание во время заставки → QR → касание → меню. Проверить рекорды/калибровку/чувствительность.
3. Меню без действий 120 с: видны жёлтые перспективные титры около 40 с, затем плавное гашение. IMU не будит; первое касание/PLUS только будит. Повторить на результате; активная игра не гаснет.
4. «Новый лабиринт» в setup/pause/result сразу открывает другую карту. «Заново» сохраняет карту и настройки. Сложный уровень 8×5 умеренно труднее, шар проходит коридоры.
5. Калибровка: сохранить удобную нейтраль, видеть X/Y «От 0» около нуля; наклон меняет значения, после перезапуска нейтраль сохранена. Сравнить 0.8/1.5 без смены калибровки.
6. Commands: четыре свайпа в области круга, «Поверни» касанием круга, обычное «Коснись», физические жесты с небольшими сопутствующими движениями. Проверить Simon, Magic Ball и рекорды.

Эти пункты ещё NOT_TESTED на 0.3.3; USB и симулятор не заменяют ответ пользователя.


Автотесты и USB не заменяют эти проверки. Фактические результаты фиксировать в [progress.md](../progress.md), дефекты — в актуальном списке задач.

1. **P0 питание:** после запуска отключить USB, играть не менее 5 минут, проверить экран/наклон/сенсор и сохранение результата; вернуть USB. При мгновенном выключении подключить USB обратно и сообщить результат. Не менять проводку и не замыкать контакты.
2. **P0 запуск:** отдельно проверить штатный запуск от аккумулятора кнопкой PWR. BAT_EN теперь удерживается с самого начала программы. Длительное PWR-выключение в NeuroCube пока не реализовано; не считать поведение заводской программы подтверждённым для новой прошивки.
3. Заставка «Привет, Андрей» читается целиком: touch → QR GitHub → повторный touch → меню; PLUS сразу открывает меню. При переключении игр заставка не появляется.
4. «Настройки» → «Калибровка» реагирует на касание. Подтвердить удобную нейтраль, дождаться «Сохранено», проверить четыре наклона и повтор после перезапуска. При движении во время сбора калибровка должна ожидать неподвижности.
5. Simon: при запуске и рестарте правила → 3–2–1; ранний ввод не принимается. Фигура явно выделяется, фазы «Смотри»/«Твоя очередь» различимы. Проверить несколько раундов и ошибку.
6. Лабиринт: оба ползунка доступны, подписи читаемы, отдельная кнопка «Играть». Проверить две сложности, удержание у стены (одно касание), отход и повторный контакт, проигрыш после превышения лимита и режим без лимита. Новая попытка возвращает настройки.
7. Commands: все шесть команд видны целиком; наклон двигает круг, поворот даёт реакцию, касание круга принимается. Проверить успех и ошибку, таймер не перекрывает текст.
8. Magic Ball: shake, свободное касание и кнопка дают ответ; быстрое двойное действие даёт один запрос. Через 300–500 мс после классики появляется парная IT-фраза, обе читаемы. Навигация имеет приоритет.
9. Проверить pause/resume, «Заново», «Далее», «Меню», короткий и длинный PLUS. Один shake — рестарт обычной игры, ответ в Magic Ball, ничего в меню.
10. После реального результата проверить рекорды после перезапуска. Старые Simon=3, legacy maze=885, Commands=1 не должны исчезнуть. Для новых настроек лабиринта рекорды независимы.

При сбое записать экран, игру, настройки, ожидаемое и фактическое действие. Диагностика: `python tools/neurocube.py logs --seconds 30`, `power`, `settings`, `records` через Python из venv. Сырые ADC/STAT не являются показанием процентов заряда.

## Скринсейвер и wake

В главном меню не касаться устройства две минуты. Оценить перспективные жёлтые титры; после последней строки подсветка должна погаснуть. Наклон/встряхивание не должны будить. Первое касание должно вернуть меню без запуска игры, второе отдельное касание выбирает игру. Повторить с PLUS, включая удержание и отпускание: первое действие только будит. На экране результата повторить и проверить сохранность результата. QR, калибровка и активная игра должны оставаться включёнными без скринсейвера. Отдельно повторить на аккумуляторе; реальное потребление не измерено.

## Приёмка исправлений 0.3.1

- Лабиринт: запомнить seed/карту, нажать «Заново» — та же карта/настройки; «Новый лабиринт» — другой seed/карта. Проверить кнопки в setup, паузе и результате; «Далее» переключает игру.
- Приближение к стене без удара не штрафует; прижатие — один контакт, отход и возвращение — следующий. Результат новой карты не выдаётся за общий рекорд.
- Commands: круг начинает ехать ещё до принятия наклона; отметка покоится без поворота; все шесть команд/подсказки и таймер не перекрываются.
- Чувствительность: пройти цикл 0.8 → 1.0 → 1.5 → 0.8 и проверить сохранение после перезапуска, калибровка прежняя.
- Повторить холодный старт PWR и работу без USB; новая аппаратная проверка не подменяется прежними 5+ минутами. Вернуть USB после теста.

## Тихое аудио 0.3.4 — после разрешённой прошивки

1. При старте mute: нет звука от обычного touch, меню, splash, QR, титров и PWR.
2. В правилах Magic Ball включить пиктограмму: игра ещё не стартует. Следующее отдельное действие запускает игру. На одном запросе ответа — один очень тихий «уоп». Сообщить слышимость и комфорт; громкий тест не повторять.
3. В Simon/Commands допустить ошибку: один тихий «кх», без повтора каждый кадр. В лабиринте обычный контакт без проигрыша беззвучен, превышение лимита — один «кх».
4. Переключить игру: настройка общая. Выключить звук: эффекты отсутствуют. Проверить сохранение обоих состояний после штатного PWR выключения/включения, сверить рекорды/нейтраль/чувствительность.
5. Убедиться, что звук не мешает тачу/жестам/LCD; mute и PWR обрывают его. Если даже этот профиль слишком громкий, оставить OFF и сообщить результат; не повышать интенсивность автоматически.
