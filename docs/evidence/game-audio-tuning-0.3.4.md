# Настройка аудио 0.3.4 — 21.10.2026

## Физическая приёмка

Идентифицированная плата 419CB819454EA93D. Исходная [rc1](game-audio-0.3.4.md) слишком тиха; пользователь попросил повторение из-за удалённого расположения устройства, затем окно до пяти минут. Все перечисленные диагностические программы загружались только в RAM с verify; после них автоматически возвращалась установленная 0.3.4 / 0eee6ee. Flash не записывалась, records/settings полностью совпали до/после.

- PCM 64: едва слышное жужжание; 256: пульсации; 512 с короткими выдержками: щелчки и пульсации. Эти профили не приняты.
- Непрерывный тон 1 кГц без переключений усилителя: PCM 512 слишком тихо, [PCM 1024](game-audio-quiet-repeat-1024-steady-5min.json) — «громкость подходящая».
- После исправления выдержек усилителя [«уоп»](game-audio-quiet-repeat-1024-uop-warmed.json): 294 воспроизведения, faults=0; пользователь «Слышен мягкий „уоп“, громкость подходит».
- [«Кх»](game-audio-quiet-repeat-1024-error-warmed.json): 52 воспроизведения, faults=0; пользователь «Да, подходит».

VERIFIED_ON_HARDWARE относится к слышимости/комфорту этих двух RAM-проб. Перед удачной пробой «уоп» один запуск по ошибке использовал прежний ELF ровного тона после ошибки сборки; он остановлен и не считается проверкой эффекта. В дальнейшем запуск выполнялся только после успешной сборки.

## Итоговая реализация

PCM peak 1024, 24 кГц, codec volume 60. «Кх» 100 мс, спад 700→300 Гц с небольшой шумовой составляющей. «Уоп» 180 мс, 600→1100→800 Гц с затуханием. Амплитуда ниже прежнего громкого теста 8191 примерно в 8 раз; акустические dB не измерялись.

[NS4150B, изготовитель, стр. 4](https://dfsimg3.hqewimg.com/group1/M00/1F/6B/wKhk7mGgjU-APHamABPHeccznSk986.pdf) указывает типовые startup 120 мс / wake 35 мс / shutdown 80 мс. Перед PCM передаются 180 мс нулей, после — 120 мс; явный stop сначала гасит PA, продолжая нули до окончания отключения. Один голос, буфер 46080 байт, аварийный alarm 550 мс. Нет блокирующего ожидания воспроизведения.

Последние указания пользователя заменяют первоначальные требования default OFF / silent splash: игровые эффекты по умолчанию ON, явный сохранённый OFF сохраняется; «уоп» при видимом приветствии и «кх» после сохранения/показа «Выключаюсь» звучат всегда, независимо от mute, по одному разу. Подсветка, зарядка и latch не изменялись.
