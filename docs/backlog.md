# Бэклог NeuroCube

[Стабильная 1.0.0 опубликована](https://github.com/odinesn1ck/neurocube/releases/tag/v1.0.0). Функциональность основана на 0.3.5 с Apache-2.0 заменой ES8311 и отдельно запрошенным PCM2560. Новые игры/настройки/миграция рекордов не включались.

## Открытые задачи

1.0.1: копирайт «© 2026, мальчик Коля + OpenAI» на выключении реализуется по запросу пользователя; ожидаются проверка галереи, сборка, CI и отдельное разрешение установки. Стабильная1.0.0 остаётся неизменной.

| P0 | LICENSE-002: прежнее распространение | Разрешение правообладателя для старого restricted кода либо отдельно согласованный план урегулирования истории/assets. Старые материалы не изменялись; [оценка](evidence/es8311-license-replacement.md#исторические-git-objects-и-assets). Новый релиз распространяет чистый snapshot и не заявляет очистку всей истории |
| P1 | MERGE-001: PR в main | Отдельное явное разрешение на merge; [PR #1](https://github.com/odinesn1ck/neurocube/pull/1) пока открыт |

## Выполнено для 1.0.0

- LICENSE-001: новый ES8311 имеет подтверждённую Apache-2.0 для RP2350; старый драйвер удалён из HEAD/новых пакетов, регрессия/CI/reproducibility PASS. [Исследование](evidence/es8311-license-replacement.md).
- AUDIO-LEVEL: запрошенный +100% PCM2560 установлен с сохранением данных; пользователь подтвердил «звук ок». [Flash](evidence/audio-pcm2560-flash.json), [приёмка/публикация](evidence/release-1.0.0-published.json).
- RELEASE-002: владелец поручил финализировать релиз; v1.0.0 опубликован, assets скачаны и проверены. Merge не включён в это решение.

## Отложено

Дополнительные игры, избранные seed/история карт, достижения/ежедневные испытания и дальнейшее энергосбережение требуют отдельных задач. Замысел — в [vision](product-vision.md).
