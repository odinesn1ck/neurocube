## Следующее расширение

Через 120 с только меню/результат, перспективный жёлтый текст, завершение по последней строке, плавное гашение, wake касанием/PLUS с поглощением первого события. Не менять BAT_EN/зарядку, не выдавать USB за физическую проверку wake. Полные критерии: [star-crawl-screensaver](tasks/star-crawl-screensaver.md).

## Не является дефектом

Краткий «телевизионный шум» при USB-старте нравится пользователю. Специально устранять или воспроизводить его не требуется; первичное уточнение сохранено в [истории питания](autonomous-power-blocker-2026-10-21.md).

Контакты стен и пагинация: исправлены, автоматические проверки пройдены. Ограниченное хранилище последних/избранных seed и агрегаты по сложности — будущая задача с отдельной миграцией; сейчас честный результат попытки без общего рекорда.
