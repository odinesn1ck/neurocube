# Физическая приёмка NeuroCube 1.0.0

Проверять на конкретной согласованной прошивке. Native, USB и framebuffer не заменяют физические результаты. Не стирайте рекорды; исходное состояние и резервная копия остаются вне Git. [Фактическое состояние](progress.md).

1. **PWR и аккумулятор:** без USB включить PWR; «Привет, Андрей» и один «уоп». Дать поработать и поиграть не менее 5 минут. Удержать PWR около 1,8 с → «Выключаюсь» и один «кх» → отпустить → устройство выключено. Включить снова: рекорды/калибровка/чувствительность сохранены. С USB питание может оставаться — допустимо сообщение «Питание осталось».
2. **Заставка/QR:** при включении касание приветствия открывает GitHub QR, повторное — меню; PLUS сразу открывает меню. Отсканировать QR телефоном.
3. **Simon:** правила → 3–2–1 → выделенные огни; несколько раундов наклонами и сенсором. Темп постепенно ускоряется только между показами, промежутки погасания видны. Подождать в своей очереди — нет тайм-аута. Пауза сохраняет темп, «Заново» сбрасывает. Удобство поздних раундов отдельно отмечать, не выводить из ранних.
4. **Лабиринт:** лимит/сложность, новое поле, retry той же карты. При новом касании стены один «кх», удержание не повторяет его; цель даёт «уоп». Шар проходит коридоры, счётчики понятны.
5. **Commands:** наклоны/повороты, свайпы и касание круга для «Поверни»; верная команда → «уоп», ошибка/тайм-аут → «кх». Небольшое сопутствующее движение не должно мешать.
6. **Magic Ball и mute:** встряхивание с правил запускает первый ответ; shake/touch/«Спросить ещё» дают одну новую пару и «уоп». Пиктограмма общая: выключить игровые звуки, перезапустить, проверить сохранение OFF. Приветствие/выключение звучат и при OFF. Вернуть удобную настройку.
7. **Титры/wake:** главное меню или результат без действий 120 с → перспективные титры → плавное гашение. IMU не будит; первое touch/PLUS только будит, второе управляет. Активная игра не гаснет. Устройство не должно терять питание/данные.

Вернуть USB после проверки. Сообщить результат по пунктам, установленную версию и любые отличия. BOOT/RESET в эту игровую проверку не входят. Стабильная публикация возможна только после закрытия лицензионного блокера и решения владельца.
