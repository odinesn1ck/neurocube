# NeuroCube — замечания по аппаратной приёмке и персонализация (21.10.2026)

> Первичные наблюдения пользователя. Сведения ниже относятся к этому этапу. Актуальное состояние: [progress](progress.md); открытые задачи: [backlog](backlog.md). Не применять старые статусы автоматически к новой версии.

Источник: ручная проверка владельца Waveshare RP2350-Touch-LCD-1.54. База: ветка `codex/neurocube-mvp`, `docs/morning-checklist.md`. Исправлять существующий проект, не переписывать с нуля. Срок подарка — 23 октября 2026.

## Подтверждено работающим на реальном устройстве
- LCD и основное меню, соседние пункты меню реагируют на touch.
- Пауза, перезапуск встряхиванием.
- Лабиринт запускается и управляется.
- «Шар ответов» выдаёт ответы.
- Физическая кнопка работает.
- Рекорды сохраняются после перезапуска.
Не регрессировать эти сценарии.

## P0.1 Исправить калибровку
Меню «Калибровка» визуально есть, но нажатие ничего не делает. Соседние пункты работают. Проверить hitbox, приоритеты touch, screen/state transition, обработчик пункта, координаты и отрисовку. Калибровка должна открыть отдельный экран с понятной инструкцией: расположить устройство привычным образом, подтвердить касанием, показать текущие показания и завершение. Нужны «Повторить» и «Назад», недопустимы ложные клики. Желательно хранить offset между перезапусками, но не рисковать существующими рекордами или форматом Flash. Добавить тест на переход именно через touch по координатам пункта меню.

## P0.2 Повтори ритм (Simon)
Сейчас игра начинается слишком быстро, цель неочевидна, активная фигура не выделена. При каждом запуске/рестарте показать заставку с краткими правилами («Запомни последовательность. Повтори наклонами»), затем обратный отсчёт 3–2–1 и только затем начать. Активная фигура должна однозначно отличаться от остальных (заливка, контур, увеличение, мигание/пульсация, не полагаться только на цвет). Разнести фазу показа образца и фазу ответа игрока, добавить указатель фазы, разумные тайминги/паузы и анимацию правильного/ошибочного действия. Не делать blocking sleep в игровом цикле. Повторный shake запускает весь стартовый сценарий.

## P0.3 Лабиринт
Нужны более сложные, разнообразные, гарантированно проходимые карты (фиксированные/сгенерированные с проверяемым маршрутом), не ломать существующую физику. Перед стартом отдельный экран настроек с ДВУМЯ сенсорными ползунками: «Сложность» и «Касания». «Сложность» регулирует геометрию и препятствия; «Касания» — допустимый лимит столкновений со стенами, либо явный режим без лимита. Уточнённая дефиниция: считать ОДНО касание на начало непрерывного контакта с препятствием, не по каждому кадру, с hysteresis/rearm. Показывать счётчик касаний и лимит на игровом экране. При достижении лимита — понятный проигрыш; при победе — итог и учёт касаний. Ползунки должны хорошо попадать под палец на 240x240, значения видны, есть кнопка «Играть»; исключить случайный запуск при регулировке. Рекорды сравнивать только для совместимых настроек/режимов, не разрушать текущие сохранения.

## P0.4 Лови команду
Сейчас виден только хвост текста команды (обрезка), назначение круга непонятно. Сделать отдельную крупную читаемую область команды (включая кириллицу, перенос или короткие фразы). Круг — управляемый объект, который заметно перемещается на экране вследствие выполнения команды. Для наклонов — движение по координатам; для поворота — очевидная визуальная реакция (траектория/вращение), для touch — цель/подсветка. Индикатор требуемой реакции, обратная связь об успехе и таймер не должны перекрывать команду. Перед первой попыткой краткая инструкция и отсчёт. Проверить отрисовку длинных команд на 240x240, перекрытия и реальную различимость команд.

## P0.5 «Шар ответов»
Дополнительно к «Спросить ещё» любое одиночное касание игровой области должно выдавать новый ответ. Касания элементов навигации/меню никогда не должны выдавать ответ: hit-test и приоритет глобального UI. Радикально улучшить визуализацию в духе мистического шара судьбы из фильма «Трасса 60» или Magic 8 Ball: объёмная сфера, блики, тёмная глубина, плавная анимация встряхивания/вращения и появления ответа, эффектное светящееся окно ответа. Создать самостоятельное оригинальное оформление, не копировать охраняемые кадры, логотипы и точный реквизит. Текст читаемый, анимация неблокирующая, без тяжёлых ресурсов и потери FPS. Оба способа запроса ответа должны идти в один application handler, с защитой от повторных touch-событий.

## P0.6 Персонализация
При каждом холодном старте/обычном включении — отдельная splash-заставка с ТОЧНОЙ строкой: «Привет, Андрей». Красивый визуальный стиль, центрирование, крупный кириллический шрифт, 1.5–3 секунды без чрезмерной задержки; затем главное меню. Не показывать при обычном переключении игр. Допустимо пропускать касанием/кнопкой. По возможности имя вынести в конфигурацию/настройку, но значение по умолчанию «Андрей». Не сломать режим USB/diagnostics.

## Общие требования
- Все глобальные функции жестов/кнопок дублируются сенсорным UI.
- Clean Architecture: game logic без Pico SDK, HAL не знает правил игры; переносимые тесты и симулятор остаются работоспособными.
- Реальные touch hitboxes должны соответствовать видимой геометрии; тексты не выходят за рамки.
- Не менять аппаратные GPIO, аккумулятор, RESET, схему Flash и сохранение рекордов без тщательной необходимости.
- Собрать Windows tests/simulator, RP2350 UF2, проверить CI; при разрешении безопасно прошить только идентифицированную плату и проверить логи. Визуальное качество и физические ощущения отмечать как требующие подтверждения пользователя.
- Работать в ветке codex/neurocube-mvp или в новой дочерней ветке с PR, без force-push и автоматического merge; обновить morning-checklist, player-guide и progress.
- Порядок: калибровка и обрезка текста -> intro/UX -> лаборатория лабиринта -> магический шар -> splash -> regression/flash. Если времени не хватает, приоритет функциональные дефекты и персонализация.

## Критерии приёмки
1. «Калибровка» нажимается в меню и открывает рабочий мастер; настройка реально влияет на IMU.
2. Simon не принимает игровой ввод до показа образца и отсчёта; активная фигура явно выделена.
3. Labyrinth: два ползунка при запуске, счётчик касаний, корректный учёт непрерывного контакта, усложнённые проходимые карты.
4. Commands: целиком читаемая команда и круг реально двигается/реагирует на её исполнение.
5. Magic Ball: shake, кнопка и касание свободной игровой зоны дают новый ответ; меню имеет приоритет; значительно улучшенная анимация.
6. Включение показывает «Привет, Андрей»; рекорды сохраняются и старые работающие функции не сломаны.

После работы предоставь коммиты/PR, UF2, результаты автотестов, перечень реально проверенного на плате, точечный повторный чек-лист. Не объявляй визуальную приёмку завершённой без пользователя.
