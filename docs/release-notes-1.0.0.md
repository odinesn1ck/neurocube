# NeuroCube 1.0.0 — подготовленный кандидат

**Не опубликован как стабильный релиз.** Функциональность заморожена на 0.3.5. Публичная стабильная поставка BLOCKED до аппаратной приёмки Apache-2.0 замены ES8311, решения по прежним публикациям и подтверждения владельца. [Готовность выпуска](evidence/release-1.0.0-readiness.md).

Автономная консоль Waveshare RP2350-Touch-LCD-1.54: Simon со скоростью от сложности и плавным ускорением до 0,5 с, детерминированные проходимые лабиринты с retry/new, Commands с физическим и сенсорным управлением, Magic Ball с 24 парными ответами. Персональное приветствие «Привет, Андрей», GitHub QR, титры через две минуты бездействия, мягкое гашение и wake без случайного действия.

Короткие «кх»/«уоп», общий сохраняемый игровой mute, независимые звуки включения/выключения. PWR 1,8 с сохраняет данные, показывает «Выключаюсь» и отключает батарейное питание после отпускания. PLUS остаётся игровой кнопкой, BOOT — сервисной. Зарядка не перенастраивается.

Изменения относительно 0.3.5: согласованные метаданные 1.0.0, MIT оригинального кода, CONTRIBUTING и актуальная документация, полный комплект сторонних notices, воспроизводимая production-упаковка и аудит истории/артефактов. Игровые механики, аппаратные драйверы и формат журнала сохранены.

В комплекте UF2/ELF/BIN, Windows simulator, исходники, LICENSE/third-party notices, руководство, manifest и SHA256. Симулятор использует mock аудио. Процедурные карты не имеют общего рекорда между разными seed. Deep sleep не включён: idle сохраняет battery latch и сканирование wake. Проверки native/USB не являются физической приёмкой LCD/ввода/батареи; отмечайте фактический результат по [чек-листу](morning-checklist.md).

Перед обновлением — разрешение, идентификация платы и свежий backup журнала вне Git; после — verify и records/settings readback. Стабильный релиз, merge и изменение visibility не выполняются автоматически.
